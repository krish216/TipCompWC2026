What changes

  • Navbar shrinks to 3 links + avatar
  • Admin tools live inside the drawer, not a separate page
  • All 6 tabs remain — nothing is lost
  • Drawer overlays current page — no context switch
  • Close drawer → instantly back to predictions/leaderboard
  • Blue dot on avatar signals admin access
  • /comp-admin route can be retired

Trade-offs

✓ No page navigation for admin tasks
✓ Cleaner navbar
✓ Content-rich tabs still work at 300px width
⚠ Drawer width (300px) is tighter than the current full page (672px) — some content like payment tables needs slight rework
⚠ Deep-linking to specific tabs (/comp-admin?tab=payments) is lost unless we add URL params
